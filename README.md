# AI Pick · 상황별 AI 추천

지금 내 상황(“내일 발표인데 PPT가 없어요” 등)을 적거나 고르면, AI 서비스 34개 중에서 맞는 것을 추천하고 같은 분야끼리 비교해 주는 사이트입니다. HTML · CSS · JavaScript만 쓰고, 빌드 과정은 없습니다.

## 실행 방법
- `index.html`을 브라우저로 열면 바로 실행됩니다.
- VS Code를 쓴다면 **Live Server**로 열어도 됩니다.
- 배포: GitHub 저장소에 올린 뒤 Netlify에서 저장소를 연결하면 됩니다(빌드 명령 없음, 게시 폴더는 루트).

## 파일 구조
```
index.html          첫 페이지
css/style.css       디자인, 밤 모드, 반응형
js/services.js      서비스 데이터 + 분야별 사용 팁
js/script.js        상황 추천, 곡선 캐러셀, 필터·검색, 상세 팝업, 비교, 토글
assets/favicon.svg  브라우저 탭 아이콘
```

## 상황 입력
- 문장을 적는 것과 상황 카드를 누르는 것이 한 입력 칸으로 합쳐져 있습니다.
- 적는 동안 문장에서 알아챈 상황이 칸 안에 옅은 빨간 태그로, 카드로 고른 상황은 검정 태그로 담깁니다.
- 태그의 ×로 빼고, 빈 칸에서 지우기 키를 누르면 마지막 태그가 빠집니다. 오른쪽 ×는 모두 지우기입니다.
- ‘추천받기’를 누르면 문장 속 조건(무료, 초보)까지 켜고 추천 결과로 이동합니다.

## 같은 분야 비교
- 카드의 **＋ 비교**로 같은 분야 AI를 2~6개 담으면 화면 아래 비교함이 뜹니다. 다른 분야를 담으려 하면 새로 담을지 물어봅니다.
- 분야 필터를 고르면 **이 분야 N개 한눈에 비교** 버튼으로 한 번에 비교할 수 있습니다.
- 비교 화면: 한눈에 결론(쉬운 것, 무료로 시작, 결제 필요) → 서비스별 ‘이럴 때 고르세요·강점·주의’ → 항목별 비교표(★ 가장 유리, 차이 있음/모두 같음) → 사용 팁

## 서비스 추가·수정
`js/services.js`의 `services` 배열에 `{ ... }` 한 덩어리를 더하면 됩니다.
상황별 추천 순서는 `js/script.js`의 `SITUATIONS` → `picks`(서비스 번호)로 정합니다.

## 디자인
- 크림색 패널 + 복숭아·연두 그라데이션 테두리, 가운데 굵은 제목, 손글씨 메모(Nanum Pen Script), 코랄 포인트 버튼
- 상황 카드 14개는 곡선(원통 안쪽) 캐러셀로 천천히 흐릅니다. 항상 저절로 흐르며, 마우스를 올리거나 키보드로 고르면 잠깐 멈추고, 끌어서 넘길 수 있습니다.
- 카드 색은 `js/script.js`의 `SIT_COLORS`, 전체 색은 `css/style.css` 맨 위 `:root` 변수에서 바꿉니다.
- 이미지 없이 CSS와 글자로만 만들어서 교체할 에셋은 파비콘뿐입니다.
- 글꼴: Pretendard(본문·제목), Nanum Pen Script(손글씨 메모)

## 접근성
- 아이콘 버튼마다 `aria-label`, 토글은 `aria-pressed`로 켜짐·꺼짐 상태를 알려 줍니다.
- 키보드(Tab, Enter, Space)로 모두 조작할 수 있고, 포커스 테두리가 보입니다.
- 운영체제의 ‘동작 줄이기’ 설정이 켜져 있으면 캐러셀 외의 애니메이션을 끕니다.
- 밤 모드는 시스템 설정을 따르고, 오른쪽 위 달 버튼으로 바꿀 수 있습니다.
