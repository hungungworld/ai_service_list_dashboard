# AI 서비스 리스트 · 상황별 AI 추천

지금 내 상황(“내일 발표인데 PPT가 없어요” 등)을 적거나 고르면, 조원 5명이 조사하고 직접 써 본 AI 서비스 34개 중에서 맞는 것을 추천해 주는 사이트입니다. HTML · CSS · JavaScript만 쓰고, 빌드 과정은 없습니다.

## 실행 방법
- `index.html`을 브라우저로 열면 바로 실행됩니다.
- VS Code를 쓴다면 **Live Server**로 열어도 됩니다.
- 배포: GitHub 저장소에 올린 뒤 Netlify에서 저장소를 연결하면 됩니다(빌드 명령 없음, 게시 폴더는 루트).

## 파일 구조
```
index.html          첫 페이지
css/style.css       털 질감 스타일, 반응형
js/services.js      서비스 데이터 (엑셀에서 옮김) + 조원 팁
js/script.js        상황 추천, 필터·검색, 상세 팝업, 음악 플레이어, 토글
assets/             이미지 에셋 (SVG)
```

## 같은 분야 비교
- 카드의 **＋ 비교**로 같은 분야 AI를 2~6개 담으면 화면 아래 비교함이 뜹니다. 다른 분야를 담으려 하면 새로 담을지 물어봅니다.
- 분야 필터를 고르면 **이 분야 N개 한눈에 비교** 버튼으로 한 번에 비교할 수 있습니다.
- 비교 화면: 한눈에 결론(쉬운 것, 무료로 시작, 결제 필요, 직접 써본 것, 국산) → 서비스별 ‘이럴 때 고르세요·강점·주의’ → 항목별 비교표(★ 가장 유리, 차이 있음/모두 같음) → 조원 비교 팁

## 서비스 추가·수정
`js/services.js`의 `services` 배열에 `{ ... }` 한 덩어리를 더하면 됩니다.
상황별 추천 순서는 `js/script.js`의 `SITUATIONS` → `picks`(서비스 번호)로 정합니다.

## CSS로 만든 부분과 이미지 에셋
| 부분 | 구현 |
|---|---|
| 카드 모양, 둥근 모서리, 조명, 바닥 그림자, 버튼 눌림 | CSS |
| 털 가장자리가 보송하게 흐트러지는 효과 | `index.html`의 SVG 필터 `#fuzz` |
| 제목·설명·버튼·레터링 | 실제 HTML 글자 (Google Fonts) |
| 털 질감, 캐릭터, 빨간 리본, 파비콘 | `assets/` 이미지 |

## 이미지 에셋 교체 방법
같은 파일명으로 덮어쓰거나, PNG로 바꿀 경우 CSS/HTML의 경로만 바꿔 주세요.

| 파일 | 쓰는 곳 | 권장 크기 |
|---|---|---|
| `assets/fur.svg` | 모든 카드·버튼의 털 질감 (반복 타일) | 512×512 PNG, 이음새 없는 털 사진, 회색 또는 투명 배경 |
| `assets/character.svg` | 하단 캐릭터, 세로 장식 카드 B의 얼굴 | 800×960 PNG, 투명 배경 |
| `assets/ribbon.svg` | 하단 빨간 리본, 알약 카드 장식 | 2000×520 PNG, 투명 배경 |
| `assets/favicon.svg` | 브라우저 탭 아이콘 | 64×64 (또는 favicon.ico) |

PNG로 바꿀 때 수정할 곳:
- 털: `css/style.css`에서 `fur.svg`를 검색해 `fur.png`로 변경
- 캐릭터: `index.html`의 `dock__char` 이미지, `css/style.css`의 `.deco-face`
- 리본: `index.html`에서 `ribbon.svg` 두 곳

## 접근성
- 아이콘 버튼마다 `aria-label`, 토글은 `aria-pressed`로 켜짐·꺼짐 상태를 알려 줍니다.
- 키보드(Tab, Enter, Space)로 모두 조작할 수 있고, 포커스 테두리가 보입니다.
- 운영체제의 ‘동작 줄이기’ 설정이 켜져 있으면 애니메이션을 끕니다.
